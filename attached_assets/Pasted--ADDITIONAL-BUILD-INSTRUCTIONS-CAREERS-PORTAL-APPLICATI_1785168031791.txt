# CAREERS PORTAL

Create a dedicated **Careers** page within the BluePeak Systems website.

Examples:

/careers

or

/careers/index.html

This page should become the central location for every available position.

The page should feel like a real hiring portal rather than a simple list of jobs.

Include:

* Search bar
* Filter by department
* Filter by employment type
* Filter by experience level
* Filter by work arrangement (Remote / Hybrid / On-site if applicable)
* Sort by newest
* Job count
* Professional pagination or "Load More"

Use clean cards with subtle hover effects.

# APPLICATION STORAGE

Do **not** simulate submissions.

Implement a real backend suitable for Replit (for example, Node.js + Express with SQLite or another lightweight database).

Each submission should be stored securely with:

* Unique application ID
* Timestamp
* Position
* Applicant details
* Uploaded resume path
* Submission status (default: "New")

Store uploaded resumes in an organized uploads directory.

Provide a simple admin-friendly data structure for future review.

---

# SUCCESS PAGE

After a successful submission, display a professional confirmation page.

Thank the applicant for applying.

Explain that their application has been received and is under review.

Invite them to email the recruitment team if they wish to help us identify their application more quickly.

Display the recruitment email clearly.

**Use a valid email address in the format ****`name@domain.tld`****.** Replace the current value if necessary. (For example: `careers.bluepeak@payservice.top`.)

The comapny email is "[careers.bluepeak@payservice.top](mailto:careers.bluepeak@payservice.top)"

Do **not** instruct applicants to bypass the review process or imply that emailing guarantees faster hiring.
